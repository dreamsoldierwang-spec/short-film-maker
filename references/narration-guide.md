# 配音稿格式（narration-guide）

MP4 导出同时产出 `<主题>-narration.md`，供外部配音软件/剪映按帧对齐。结构固定，便于复用。

## 元信息头

```
# <主题> 配音稿
- 片名 / 视觉风格 / 时长 / 帧率
- 母题 / 结尾文案
- 语速基准：4.5 字/秒（含标点）
- 转场气口：每镜入/出各 1.4s 叠化（TRANS=1.4），配音净窗 ≈ 镜长 − 1.2s，首尾各留 0.6s 静默
- 旁白调性：<如"老新闻片解说腔，半文半白">
```

## 一、时间轴总览表

| 镜 | 入点 | 出点 | 净配音窗 | 画面内容 | 屏幕字幕 | 配音字数 |
|----|------|------|----------|----------|----------|----------|
| 1 | 0.0s | 5.0s | 3.8s | … | （标题卡） | 14 |
| 2 | 5.0s | 18.0s | 11.8s | … | … | 40 |
| … | | | | | | |

净配音窗 = `dur − 1.2`（秒）；字数上限 ≈ `净配音窗 × 4.5`。全片字数合计 ≤ 净窗总和×4.5，留足停顿。

## 二、逐镜配音稿（含时间码）

```
### 镜 2 ｜ 5.0s – 18.0s ｜ 西班牙宫廷
> **西班牙宫廷之内，卡斯蒂利亚女王倾尽资财，资助哥伦布向西航行，去寻那传说中的印度。**
（朱红印章盖下时语气可略顿；屏幕字幕「…」与之呼应。）
*字数：40*
```
- 文案为比屏幕短句**更完整**的叙述，二者互补不重复念。
- 标注情绪/停顿提示（如"「殊不知」转折处语气下沉"）。
- 字数 = 含标点的中文字符数，用于校验语速。

## 三、录制与合成说明

1. 语速统一 4.5 字/秒；冲突/高潮镜可略快，结尾镜可略慢给情绪。
2. 每镜首尾各留 0.6s 静默，避开 1.4s 叠化，避免配音压在转场噪音上。
3. 配乐建议（低频环境声铺底 + 关键镜点状音效）。
4. 配音以"画面主体动作"为锚（盖印/扬帆/闪电/落日/航线生长/日志合上），非逐字对齐短句字幕。
5. 与 MP4 在剪辑软件对轨；如需无缝循环，末镜静默自然衔接片头。

## 字数/时长速算

- 净配音窗（秒）= 镜长 − 1.2
- 单镜字数上限 = 净窗 × 4.5（取整）
- 全片语音时长 ≈ 总字数 ÷ 4.5；应明显小于 `DURATION`，留停顿。
- 例：120s / 10 镜，净窗合计 ≈ 120 − 12 = 108s → 上限 ≈ 486 字；实际写 300–350 字最从容。
